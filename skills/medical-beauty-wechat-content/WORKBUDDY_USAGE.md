# WorkBuddy 使用说明

## 这个 skill 的名字

`medical-beauty-wechat-content`

中文可以理解为：**医美公众号内容工作流 skill**。

它不是普通“写文章提示词”，而是一套公众号运营方法：

- 先判断产品是否值得写
- 再判断搜索入口和转化价值
- 再整理成公众号选题
- 再根据素材写文章
- 最后复盘数据，决定下一篇追什么

## 推荐给 WorkBuddy 的标准指令

### 判断产品值不值得写

```text
用 medical-beauty-wechat-content，帮我判断【产品名】最近值不值得写。
请按：小红书/视频号/公众号搜索、机构端是否在推、用户是否有拿货需求、风险和转化价值分析。
最后给我下一篇最建议写的标题。
```

### 根据素材写公众号

```text
用 medical-beauty-wechat-content，根据以下素材写一篇公众号草稿。
主题：【主题】
要求：精简、有实质内容，不要只写适合人群，要包含产品详情、区别、使用思路、搭配、注意事项、引流窗口和免责声明。
风格：大白话、渠道视角、像我之前写的公众号。
素材如下：
【粘贴素材】
```

### 复盘公众号数据

```text
用 medical-beauty-wechat-content，帮我复盘这篇公众号。
文章标题：【标题】
数据：阅读量【】、搜一搜占比【】、分享【】、加微信人数【】、问价人数【】、成交人数【】。
请判断为什么有/没有流量，为什么转化强/弱，下一篇应该追什么选题。
```

### 本周选题规划

```text
用 medical-beauty-wechat-content，帮我做本周公众号选题。
目标客户：个人自用、小代理、美容院/工作室、机构工作人员。
重点方向：水光、刷酸、术后修复、再生材料、拿货前先看、真假防伪、产品对比。
请给我 10 个选题，并按搜索价值、转化价值、风险排序。
```

## WorkBuddy 输出时最好包含

1. 是否值得写
2. 为什么值得/不值得
3. 适合写成哪类文章
4. 最建议的标题
5. 风险提醒
6. 引流关键词
7. 下一篇追题
