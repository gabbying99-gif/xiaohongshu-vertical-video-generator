# Style And Components

## User Style

Write like an experienced channel-product seller explaining products to customers in plain Chinese:

- Start from a real customer problem, not from ingredients.
- Use direct, practical language.
- Keep product information clear but not overly academic.
- Always explain: suitable people, unsuitable people, usage idea, cautions, and what to ask before buying.
- Keep the user's personal judgment, but avoid exaggerated promises.
- Convert outside references into the user's own wording; do not copy large blocks from competitors.

Useful opening patterns:

- 很多人不是产品买错了，是搭配没选对。
- 最近问这款的人很多，我整理一篇比较好懂的。
- 如果你是油皮、闭口、出油暗沉，这篇可以先看。
- 这款不是所有人都适合，先把适合和不适合讲清楚。

## Fixed Disclaimer

Every article must include a disclaimer. Do not omit it even for skincare or non-injection products.

Default natural version:

```text
注：以上为个人整理的产品信息和建议使用思路，请根据自己的皮肤状态、项目情况和耐受程度判断。涉及医美操作的内容，建议在正规医疗机构，由专业医生在严格无菌条件下进行。

本文面向非特定一般群体，仅作产品资料整理、护肤思路分享和科普参考，不针对任何个人作医疗诊断或治疗建议，也不能替代专业医生面诊。医疗美容属于医疗行为，应在合规医疗机构由合规专业人员完成。相关内容仅供参考，不作为商业宣传用途；如有侵权，请及时联系删除。
```

Use the stricter original version if the user asks:

```text
注：以上为建议使用方式，请根据自身情况使用该产品，建议在正规医疗机构，由专业医师在严格无菌的条件下进行操作。

本文是针对非特定一般群体的科普或者叙事内容，不针对任何单独的医疗诊断和治疗，请不要将本文内容当做具体的医疗建议和诊疗方案。医疗美容属于医疗行为，需要在合规的医疗机构由合规的专业医生执行诊疗活动。相关内容仅供阅读者参考，不作为商业宣传用途，版权归原作者所有。如有侵权，请及时联系我们予以删除。本公众号拥有对此声明的最终解释权！
```

Softer skincare/channel-goods version:

```text
注：以上内容为个人整理的产品信息、使用思路和护肤经验分享，不同肤质、项目状态和耐受程度会有差异，请根据自身情况理性选择。

本文仅作产品资料整理和日常护肤参考，不构成针对个人的医疗建议或诊疗方案。如涉及医美项目、术后修复或特殊皮肤问题，建议先咨询专业人士。相关图片及资料如来源网络或品牌公开资料，版权归原作者所有；如有侵权，请联系删除。
```

## Lead Window

Every post must include the user's contact path and should include two paths:

1. Scan/add friend path for low-friction leads.
2. Private-message/comment keyword path for higher-intent leads.

Principles:

- Do not only say "扫码加我"; give the user a reason to add.
- Do not depend on users voluntarily writing a remark; many users will not do it.
- Do not expose price tiers or wholesale rules in public posts.
- Do not ask directly "自用还是商家" as the first screening question if it may invite price-fishing.
- Use need-based screening first, then decide whether to send retail, matching, dropshipping, or wholesale information.
- Separate use cases internally: self-use, dropshipping, wholesale, salon/studio.
- Use one unique keyword per article to track source.
- Make private-message keywords visible because higher-intent users often trust this path more.
- Put the contact card/QR code after the disclaimer or directly after the lead window, depending on layout.

General version:

```text
如果你不确定自己适不适合这款，可以加我时备注「文章关键词」。
也可以在公众号私信/留言发送「文章关键词」，会自动回复我的微信号和产品说明。

你可以把肤质、想改善的问题、现在用的产品、预算发我，我先帮你判断适不适合，再看要不要拿。
```

More natural conversion version:

```text
如果你看完还是不确定自己适不适合，可以私信/留言「文章关键词」，系统会自动回复我的微信号。

加我后不用一上来就买，可以先发：肤质 + 想改善的问题 + 现在用的产品/做过的项目。我先帮你判断这款适不适合你，再看是自用、少量拿，还是需要搭配别的产品。
```

Anti-price-fishing version:

```text
如果你不确定自己适不适合这款，可以加我看看。

我这里可以帮你看：
1. 这款适不适合你的肤质/项目情况
2. 自用应该怎么搭配更合适
3. 有没有更适合你预算的同类产品
4. 已经做过项目的，后续怎么修护更稳

想了解的话，可以私信/留言「文章关键词」，系统会自动回复我的微信。
```

For channel products where price fishing is likely:

```text
如果你是自己用、帮客户搭配，或者想少量了解这类产品，也可以加我沟通。具体规格和方式，我会根据你的用途单独发，不在文章里统一写。
```

First WeChat screening question:

```text
你是想了解这款自己用合不合适，还是手上有客户想搭配这类产品？
```

Product/channel version:

```text
如果你是个人自用、小代理、一件代发，或者美容院/皮肤管理店想少量拿货，可以私信/留言「产品名」。
系统会自动回复我的微信号和基础说明。

加我后可以直接备注：自用 / 代发 / 商家 / 拿货，我按你的用途发对应版本。
```

B-side version:

```text
如果你是美容院、皮肤管理店、小工作室，想了解少量拿货或一件代发，可以私信/留言「产品名商家」。
我可以按你的项目和客群，帮你看适合拿哪些规格、怎么搭配更好出。
```

End-section order:

1. Short lead sentence.
2. Private-message keyword.
3. Contact card/QR code or WeChat ID.
4. Fixed disclaimer.

If the article has strong medical-beauty risk, put the disclaimer before the QR/contact card.

## Follow-Up Scripts

Added but silent:

```text
你好呀，我看到你是从公众号过来的。你是想了解文章里的这个产品，还是想按肤质/需求看看更适合哪款？可以直接发：肤质 + 想改善的问题 + 预算，我先帮你判断。
```

Asked price:

```text
可以的。我先确认一下你是自用、帮客户用，还是想拿货/代发？不同规格和数量价格不一样，我按你的用途发对应版本，避免你买错。
```

Slow reply:

```text
我先把这款适合/不适合的情况发你，有空再看。简单说，如果你主要想改善 XXX，可以考虑；如果现在皮肤在敏感、爆痘或项目恢复期，就先不要急着叠加。
```
